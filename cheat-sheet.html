🌳 1. AI 家族樹與學習法

包含關係：AI（人工智慧）⊃ ML（機器學習）⊃ DL（深度學習，神經網絡）⊃ GenAI（生成式 AI）。

GenAI 定義：create new content and ideas（文字、圖片、音樂、程式碼），重點在「創造新內容」，不是做純預測。

Diffusion Model（擴散模型）：Imagen 底層技術，關鍵字是 refining noise into structured data（把隨機雜訊一步步精煉成結構化圖片）。

三大學習法（認資料型態）

  • 監督式 Supervised 資料有標籤、有人工註記。看到 labeled data、manually tagged、predict based on past data ➔ 選 Supervised。
  • 非監督式 Unsupervised 資料沒有標籤。模型自己找自然分群或異常。看到 unlabeled、natural groupings、anomaly detection ➔ 選 Unsupervised。
  • 強化學習 Reinforcement 沒有標準答案，靠環境中試錯。看到 trial and error、positive/negative score、reward ➔ 選 Reinforcement。

資料型態

  • Structured（結構化）：表格、資料庫、數字（行列清楚）。
  • Unstructured（非結構化）：自由長篇文字（open-ended text）、照片、影片、音訊。

🏛️ 2. 基礎模型與 Google 模型家族

  • Foundation Model（基礎模型）：海量資料預先訓練好的「通才」大模型，具備多任務泛化能力。
  • Multimodal（多模態）：原生同時看懂處理文字、音訊、圖片、影片、程式碼（Gemini 原生特性）。

Google 模型家族

  • Gemini：旗艦多模態閉源大模型（Google 全能王）。
  • Gemma：開源、輕量級模型（Open Weights）。看到「自架環境、重視隱私、成本敏感、客製化權重」➔ 選 Gemma。
  • Imagen：文字生成圖片（Text-to-Image）。
  • Veo：文字/圖片生成高品質影片（Text-to-Video）。

運算晶片

  • TPU（Tensor Processing Unit）：Google 專為神經網絡與矩陣運算設計的專用晶片（ASIC），訓練大模型省電又極速。
  • GPU：通用圖形運算晶片，支援各類平行計算。

✍️ 4. Prompt 提示詞工程技巧

  • Zero-shot：零範例，直接命令（no examples）。
  • One-shot / Few-shot：給一個或少數幾個範例（provide examples）。
  • Role Prompting：設定角色與受眾（act as、persona）。
  • Chain-of-Thought (CoT) 思維鏈：叫模型「一步步思考」（step-by-step reasoning），解決複雜邏輯與數學。
  • Prompt Chaining 提示鏈：大任務拆步驟，前一步輸出當下一步輸入（output becomes input）。
  • ReAct：邊思考邊用工具（synergy of reasoning and acting）。

🎛️ 5. 超參數調校（Hyperparameters）

  • Temperature（溫度）：控制隨機性與創意（0 ~ 1）。
    • 低溫（0 ~ 0.2）：嚴謹、固定、不可亂編 ➔ 寫程式、合約審查、事實問答、摘要。
    • 高溫（0.8 ~ 1.0）：天馬行空、多樣性 ➔ 寫小說、創意行銷。
    ⚠️ 考場陷阱：模型產生幻覺、看不懂諷刺，選項寫「調高溫度」絕對是錯的！調高只會胡扯得更嚴重。
  • Top-P（核採樣）：從累積機率排名前 P% 的候選詞庫挑選。
  • Safety Settings：過濾仇恨、暴力等有害內容。

🤖 6. Agent 代理人世界與多代理系統

  • Agent（代理人）：大模型 ＋ 工具調用（APIs）＋ 自主規劃。能代表人類執行具體行動。
  • Multi-Agent System（多代理系統）：
    • 核心概念：多個專門特化的 Agent 彼此分工協調。
    • 決勝關鍵字：complex tasks ＋ coordinated AI functions。
    • 淘汰誘餌：選項寫「單純固定規則（rule-based repetitive）」或「合併成單一無差別模型（single undifferentiated）」一律淘汰！

🧰 7. Agent Platform（原 Vertex AI）核心工具

  • Model Garden（模型花園）：模型超市。提供 Google 自家、開源（Llama, Gemma）、第三方合作模型。
  • Agent Studio（舊 Vertex AI Studio）：無程式碼/低程式碼 Prompt 原型設計與調參環境。
  • Model Registry（模型登記處）：管理追蹤自訓/微調模型的版本庫。
  • Agent Search（舊 Vertex AI Search）：企業內部搜尋，專門串公司文件，提供 Pre-built RAG。

🎧 8. 客服四件套與實用產品

  • Agent Assist（客服真人助手）：在真人客服通話時，於螢幕即時跳出建議與手冊，通話結束後自動總結。關鍵字：assist human agents in real-time。
  • Conversational Agents（舊 Dialogflow CX）：第一線自動處理客戶問題的AI 聊天/語音機器人。關鍵字：virtual agent、automated customer self-service。
  • Conversational Insights（對話分析）：通話事後大數據分析。分析成千上萬通錄音的主題與客戶抱怨趨勢。關鍵字：analyze call logs、customer sentiment trends。
  • Document AI：從紙本掃描、PDF、發票、合約中抓取欄位與表格資料。
  • Gemini Notebook（舊 NotebookLM）：個人研究筆記，只依據上傳的研究資料問答。

🛡️ 9. 負責任 AI（Responsible AI）與資安

  • Explainability（可解釋性）：能說清楚模型決策的理由。在貸款、醫療、求職篩選等高風險領域是法規必備。
  • Transparency（透明度）：誠實告知使用者正在與 AI 互動；圖片加 SynthID 浮水印。
  • Fairness / Bias（公平性）：避免對少數族群造成不公平待遇。
  • PII 去識別化：遮蔽個人身分識別資訊（身分證號、信用卡號）。
  • SAIF（Secure AI Framework）：Google 的 AI 資安指導框架。
  • Security Command Center (SCC)：Google Cloud 的中央資安監控中心。

💼 10. 企業導入策略與決策

  • Problem-First（痛點優先）：企業導入 AI 第一步，永遠是先釐清具體商業問題（determine business problem first），不是先選模型。
  • 導入階梯（由輕到重）：現成 API ➔ Prompt + RAG ➔ Fine-tuning 微調 ➔ 從頭自訓（極少需要）。
  • Open Approach（開放架構）：避免被單一廠商綁死（avoid vendor lock-in）。
  • Rule-based 三題考點秒辨析：
    • 交給傳統自動化？➔ 重複且規則固定（repetitive rule-based）。
    • 絕對不能給 GenAI？➔ 結果必須絕對固定不變的合規審核引擎。
    • 交給 Multi-agent？➔ 複雜且需要多方協調的任務（complex & coordinated）。
